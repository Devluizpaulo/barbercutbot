🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Container não inicia:
  → docker-compose logs
  → docker-compose restart
  → Verificar recursos: free -h

Não consigo acessar externamente:
  → Verificar IP: curl ifconfig.me
  → Verificar firewall GCP console
  → Testar localmente: curl localhost:8080

Memória insuficiente:
  → Adicionar swap: sudo fallocate -l 2G /swapfile2
  → Limitar execuções N8N antigas
  → Considerar upgrade

Disco cheio:
  → docker system prune -a
  → sudo journalctl --vacuum-time=3d
  → Limpar backups antigos

Esqueci senha N8N:
  → cat ~/evolution-saas/.env | grep PASSWORD
  → cat ~/evolution-saas/INFO.txt
