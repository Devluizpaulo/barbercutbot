# **App Name**: barbearia-saas

## Core Features:

- Multi-Tenant Dashboard: A centralized dashboard to manage multiple barber shops, ensuring data isolation for each.
- Real-Time Metrics: Display real-time metrics for each barber shop, offering insights into performance and customer trends.
- Appointment Scheduling: Enable barber shops to manage and track appointments through a calendar interface.
- Client Management: Allow barber shops to maintain and organize customer information, preferences, and history.
- Financial Tracking: Provide tools for financial management, including income, expenses, and payment tracking for each shop.
- User Authentication: Secure user authentication using Firebase Authentication for login and registration.

## Style Guidelines:

- Primary color: Deep blue (#22427A) for trust and reliability.
- Background color: Light gray (#F0F4F7) for a clean and professional look.
- Accent color: Muted gold (#A98D6F) to signify luxury and tradition, reminiscent of classic barbering.
- Headline font: 'Playfair', a serif font that provides an elegant and classic touch, well-suited to headers.
- Body font: 'PT Sans', a sans-serif font, is a body font to increase readability.
- Use sharp, vector-based icons for a modern and clean look. Icons should represent the tools and services of a barber shop, and use the muted gold as an accent color.
- A grid-based layout to present data in a clear, organized manner.
